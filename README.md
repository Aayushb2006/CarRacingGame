# CarRacingGame
Car racing simulator tracking best lap through a timer.
2D top down racing game with acceleration and breaking, paired with rotational steering, collision detection and a lap timer. Coded with Python and tools such as Pygame were used in the development of this game.
After developing upon the base tutorial, I added my own lap time feature that monitors the best lap time around the track and displays it upon the screen
